# CodeInShorts

Daily animated coding Shorts for [youtube.com/@codeinshortsdev](https://www.youtube.com/@codeinshortsdev).

- `specs/epNNN.json` — one episode (LeetCode walkthrough or phone-screen tip) plus its YouTube title, description and tags
- `engine.js` — draws the 1080×1920 animation and generates original lo-fi music (no copyright issues)
- GitHub Actions renders new specs to MP4 and publishes them on GitHub Pages (`/videos/epNNN.mp4`, `/videos.json`)
